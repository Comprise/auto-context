# Test suite audit (security gaps excluded)

Coverage (go test -cover, per package): cmd/auto-context 86.8, config 91.2, docstate 92.2, frontmatter 98.1, fsutil 79.1, gitx 84.3, hashing 88.7, hooks 93.4, logx 86.2, project 61.8, rootindex 92.4, session 89.5, textx 100, units 94.8.
All pass on linux. cmd/auto-context ran in 0.37s with -count=1: the "~15s" is not reproducible (likely cold build / go vet / first compile of test binary with git-heavy runs on a cold cache). No slow test found; slowest single test 0.05s.

Findings
1. Medium internal/project/project.go (Orphans:163, UpToDate:223, AckTouched:239, Warnings:143, Prewarm:196 at 0-50%) - package coverage 61.8%; these are only exercised indirectly through hooks/stop tests. Suggested: direct tests in internal/project (orphan docs listing, AckTouched with mixed documented/undocumented/failed units, UpToDate after source edit).
2. Medium cmd/auto-context/changes.go:9 (63.6%) - runChanges error paths (bad args -> 2, non-repo -> 1, WriteChanges error -> 1) untested. Suggested: table test of exit codes and stderr.
3. Medium cmd/auto-context/main.go:42-60 (main 0%, start fallback) - hook run with failing getwd and CLAUDE_PROJECT_DIR set/unset (must exit 0) has no test. Suggested: call start() with failing getwd func for hook and non-hook args.
4. Medium internal/fsutil/fsutil.go:201,249,260 (ReadDoc, WriteDoc, WriteState 0%) and writeAtomic:268 (61.9%) - public write/read entry points of docs/state untested directly; writeAtomic error branches (rename/sync/tmp-cleanup failure) not hit. Suggested: round-trip tests, size-limit on ReadDoc, state dir created, tmp file not left behind on failure.
5. Medium internal/hooks/testdata/permission_request.json - fixture is not referenced by any Go test (grep finds no use); either dead or the intended Codex payload decoding test is missing. Suggested: decode it in permission_request_test.go and assert Input fields (null transcript_path/description tolerated).
6. Medium internal/hooks/hooks_test.go:100-123 (TestSessionStartGolden) - golden compares exact bytes incl. any path/OS specifics; only one golden covers SessionStart; Stop/PreToolUse/Codex outputs have no golden (substring asserts only). Suggested: add goldens for Stop block message and Codex SessionStart; normalize temp-root paths and \r\n so it holds on Windows.
7. Medium Windows/macOS gaps: many tests skip on windows (permission_request_test.go:33, pre_tool_use_test.go:131,157,178 LookPath/sh shim; docstate_test.go:141; logx_test.go:156,240; session_problems_test.go:21,26) and shim_test.go:16 skips non-linux/darwin, so on Windows the PATH-resolution logic for the CLI (findable auto-context binary) is untested. CI matrix does run all three OSes, but skipped tests mean coverage there is lower. Suggested: Windows variant that writes a .bat/.exe-named fake (PATHEXT) instead of skipping; unit-test the pure path-join (commit 8a4e633 "join with /") with explicit Windows-style input independent of GOOS.
8. Medium internal/hashing/hashing_test.go:330-340 (TestUseStats...SameSize) - restores mtime with Chtimes to the original ModTime and asserts a size change is seen; fine, but line 200 ignores the Chtimes error and relies on "past" mtime; on filesystems with coarse mtime (HFS+, FAT, some CI Windows) same-second same-size edits aren't detectable, and a test relying on an unrestored mtime would flake. Suggested: check Chtimes error (t.Fatal) at :200 and always set explicit mtimes rather than relying on wall-clock differences.
9. Low internal/hooks/agent_test.go:120,134; hooks_test.go:487; permission_request_test.go:44,53; pre_tool_use_test.go:142-187; gitx_test.go:68,83,99; units_unix_test.go:91 - t.Setenv on PATH/CLAUDE_PLUGIN_ROOT/GIT_DIR. No test calls t.Parallel today (grep: zero), so these are safe now, but adding t.Parallel to any package (which t.Setenv panics on) would be blocked; and subprocess tests inherit the dev's own env (GIT_*, HOME gitconfig, CLAUDE_PROJECT_DIR) because they use os.Environ(). Suggested: TestMain per package that scrubs GIT_*/CLAUDE_* and sets HOME/GIT_CONFIG_GLOBAL=/dev/null so a developer's global git config (e.g. init.defaultBranch, commit.gpgsign) cannot affect results.
10. Low git availability is handled inconsistently: gitx_test.go:14, session_problems_test.go:36,165 skip when git is missing, but cmd/auto-context/main_test.go:592-989 and internal/units/git_test.go shell out to git without a LookPath skip, and rely on -c user.name per call (some at main_test.go:863,989 omit identity: fail if no global git identity and a commit is made). Suggested: shared helper requireGit(t) and identity via env GIT_AUTHOR_*/GIT_COMMITTER_*.
11. Low Duplicated helpers: write(t, root, rel, content) is copy-pasted in 7 test files (docstate, hooks, session, project, hashing, cmd/auto-context, plus frontmatter variant); git init/commit wrappers duplicated in cmd/auto-context/main_test.go (lines 592, 634, 694, 755, 777, 863, 989 - seven near-identical exec.Command("git", ...) closures) and units/git_test.go:18. Suggested: internal/testutil package (WriteFile, InitRepo, Git, RequireGit).
12. Low internal/hashing/hashing_test.go:195-205 (TestSaveOnlyWhenDirty) - sets cache file mtime to the past then checks it is unchanged after Save; passes if Save is a no-op always only when the assertion compares mtime not content; also error of os.Chtimes ignored. Verify the assertion would fail if Save wrote unconditionally (mutation check).
13. Low internal/hooks/permission_request_test.go:19-30 (TestPermissionRequestSilent) - asserts only out==nil for refusal cases; does not have a mirror test list proving the allowed commands (status, ack <unit>, changes) are approved exactly; a PermissionRequest that always returned nil would pass the Silent test, so positive-path test must exist (verify at :40-77) for each subcommand variant.
14. Low internal/config/config.go:179,188 (typeProblem, Describe 66.7%), session.go:206 MarkConfigNotified 0%, session.go:29 FromTree 0%, session.go:139 RemoveStale 66.7%, units.go:143,146 WarningCount/Stat 0%, gitx.go:79 Brief 0%, walk.go:544-549 fileinfo shim methods 0% - small untested helpers; MarkConfigNotified (once-per-session notice dedupe) and RemoveStale (age cutoff) are behavioural and worth direct tests: notice emitted once then suppressed; stale snapshot older than TTL removed, fresh kept.
15. Low cmd/auto-context/shim_test.go:16-21 - shim test only runs on linux/darwin and arm64/amd64; the shim's platform/arch detection (uname mapping, unsupported-arch message, Windows git-bash path) is not unit-tested for other values. Suggested: parameterize shim via env override of uname (fake uname on PATH) to cover darwin/arm64, x86_64->amd64, aarch64->arm64 and unsupported cases on any host.

Notes: no flaky sleep-based tests found (no time.Sleep in tests); map-order dependence not observed in grep; temp dirs all via t.TempDir(). Slow-test question: nothing >0.1s; the cmd/auto-context time is dominated by spawning ~25 git subprocesses and `go test` compile/link; use `go test -count=1 -v` to confirm on the slow machine.
