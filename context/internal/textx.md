# internal/textx
Очистка текста из репозитория перед выводом в лог, терминал или контекст Claude.

## Назначение
Одно правило для всех мест, куда попадает чужой текст (ошибки с путями, summary, сообщения git): без управляющих и форматных символов, ограниченной длины.

## Публичный API / точки входа
- `Clean(s)` — управляющие и форматные символы (переводы строк, ANSI, bidi) в пробелы.
- `Cap(s, max)` — первые `max` рун и `…`, если строка длиннее.
- `Line(s, max)` — `Clean`, свёрнутые пробелы, `Cap`.
- `Err(err)` — текст ошибки одной строкой до 200 рун.
- `StripControls(b)` — для многострочного вывода: убирает управляющие символы (C0, DEL, C1 и сырые байты 0x80–0x9F вне UTF-8) и форматные Unicode Cf (bidi-переопределения, нулевой ширины, BOM), кроме `\n` и `\t`; остальное, в том числе невалидный UTF-8, байт в байт; текст без них возвращается как есть.
- `BOM` — константа `\ufeff`.
- `EOL(s)` — `\r\n`, если первая строка `s` кончается на `\r\n`, иначе `\n`; общий помощник для frontmatter и rootindex.

## Связи
Зависит от: только стандартная библиотека.
Используется в: `cmd/auto-context`, `internal/logx`, `internal/project`, `internal/rootindex`.
