# internal/filestat
Отпечаток файла для обнаружения изменений (mtime и размер) — общий тип для обнаружения, снимка сессии и хуков.

## Назначение
Нейтральный лист графа зависимостей: `units` записывает отпечатки при обнаружении, `session` хранит их в снимке хода, `hooks` сравнивает. Раньше тип жил в `units`, и `session` зависел от тяжёлого пакета обнаружения только ради него.

## Публичный API / точки входа
- `Stat{MtimeNs, Size int64}` — mtime в наносекундах и размер; сравнивается через `==`.
- `Of(fi)` — отпечаток `fs.FileInfo`.

## Связи
Зависит от: только стандартная библиотека.
Используется в: `internal/units`, `internal/session`, `internal/hooks`.
