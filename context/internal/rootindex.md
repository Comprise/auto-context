# internal/rootindex
Генерирует и обновляет секцию оглавления юнитов в корневом индексном файле (CLAUDE.md или AGENTS.md).

## Назначение
Список юнитов с однострочными описаниями — карта проекта для агента. Пакет владеет только участком между маркерами.

## Публичный API / точки входа
- `Entry{Unit, Summary}`, `Render(entries)`, `Update(root, name, entries)`, `ErrBrokenMarkers`, `MaxSize` (2 МиБ).
- `name` — имя индексного файла (`Project.IndexFile()`).
- `Check(root, name)` — без записи: что `Update` отклонил бы (битые маркеры, ссылка наружу), для `auto-context status`.

## Устройство и потоки данных
Маркеры `<!-- auto-context:units -->` и `<!-- /auto-context:units -->` — только целые строки вне блоков кода; секция — от открывающего до закрывающего маркера. BOM в начале файла при поиске маркеров не мешает и при записи сохраняется. Нет маркеров — секция дописывается в конец. Строка-заголовок сразу после открывающего маркера — заголовок пользователя, сохраняется; иначе `## Units (details: context/<unit>.md)`.

## Инварианты и подводные камни
- Summary чистится: без управляющих и форматных символов, без `<!--`/`-->`, не больше 200 рун (при обрезке плюс `…`). Юниты с обратной кавычкой или переводом строки пропускаются; `_root` не попадает.
- Закрывающий маркер без открывающего (или раньше него), открывающий без закрывающего и больше одного открывающего или закрывающего маркера — `ErrBrokenMarkers`, файл не меняется; лишние маркеры пользователь убирает сам.
- Строки внутри огороженных блоков кода (``` или ~~~ от 3 символов, закрывает забор того же символа не короче) маркерами не считаются — это примеры. Отступ забора любой, в отличие от CommonMark: забор в пункте списка смещён отступом пункта. Незакрытый забор блоком не считается; перед дописыванием секции `Update` закрывает его (он и так шёл до конца файла), иначе забор, закрытый пользователем позже, проглотил бы секцию. `Check` снимает BOM так же, как `Update`.
- Запись — `fsutil.WriteDoc`: ссылка на `.md` в репозитории (AGENTS.md) обновляет цель, иная ссылка — ошибка без чтения и записи.
- Концы строк вставляемых строк — по первой строке файла: `\r\n`, если она кончается на CRLF, иначе LF (пустой файл и файл без перевода строки — LF).

## Связи (зависит от / используется в)

Используется в: `cmd/auto-context`, `internal/hooks`, `internal/project`.
